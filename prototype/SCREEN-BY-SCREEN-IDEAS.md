# Decibels — поэкранный разбор + идеи для нашей игры

Для каждого скриншота: 👁 что вижу · ⚙️ функция/как работает · 💡 идея к нам.
Порядок — как присылались.

## 1 (IMG_2820) — Подземелья
👁 Три режима: Зомби-атака, Легенды, Боссы (дракон). У каждого «ключи 2/2», кнопка «Ввести».
⚙️ Отдельный контент вне основной кампании; вход стоит **дневных ключей** (лимит 2/день) — крючок «зайти каждый день».
💡 Оставляем режимы+дневные ключи. Наш твист: каждый режим показывает **грань реалистичного движка** —
- Зомби = расчленёнка/нежить (ползёт без ног, дерётся без руки);
- Боссы = огромный враг с **разрушаемыми частями** (крыло/голова/слабая точка);
- Легенды = «киношные» дуэли-челленджи. Плюс уровни сложности = наши `modifiers`.

## 2 (IMG_2821) — Улучшения
👁 Множители «атака ×2.59 / HP ×638», открытие юнитов (Пират открыт; Стрелок/Мушкетёр за монеты), Производство еды 0.18/с, Здоровье базы. Вкладки Улучшения/Эволюция.
⚙️ Классический idle-сток: копишь монеты в бою → покупаешь апгрейды → множители/экономика растут.
💡 Оставляем idle-апгрейды и «еду» как экономику спавна. Наш твист: апгрейды **видно в бою** —
«острее клинки» = сильнее кровотечение, «тяжелее броня» = меньше пробитие по части, «лучше стволы» = чаще хедшот. Числа привязаны к нашей модели тела, а не абстрактны.

## 3 (IMG_2822) — Битва (поле боя)
👁 Две базы (корабль↔башня) с HP, дорожка, декор; снизу карты спавна за 🍗 и активные умения; скорость ×1.25.
⚙️ **Ядро цикла:** в бою копится еда → тратишь на юнитов; умения на откате → всплески. Армия воюет сама.
💡 Это ровно наш движок. Забираем механику «спавн за еду + умения с откатом» как есть, а сверху кладём **наш реалистичный бой**: раны по частям, кровь, выбитое оружие, хедшот. Плюс **слоу-мо камера** на добивании/расчленёнке и опционально **тап по зоне** для наводки умения (даёт тактику, которой в оригинале мало).

## 4 (IMG_2823) — Карты (31/31)
👁 Коллекция карт с уровнями (жнец, дракон, дрон, обелиск, бомба, троян, шприц, роза…), покупка ×1/×10/×50.
⚙️ Гача-коллекция: карты дают баффы/призывы; дубли повышают уровень.
💡 Оставляем коллекцию. Наш твист: карты-призывы/эффекты становятся **реальными кастами** в движке — троян спавнит отряд, метеор = AoE с уроном по частям тела, шприц = хил (стоп кровотечения). Уровень карты = сила эффекта. Награда за 100% коллекции.

## 5 (IMG_2824) — Умения (18/18)
👁 Активный «набор из 3» (Набор 1/2/3) + сетка пассивок: заморозка, взрыв, метеор, апперкот, кровь, лечение, топот, рывок, мультиубийство. Качаются зельями.
⚙️ Активные юзаются в бою (откат), пассивы дают постоянные бонусы. Наборы = лоадауты под контент.
💡 У нас статусы уже есть (заморозка→раскрошить, горение, оглушение) — вешаем умения на них через `cast()`. Пассивы → в бандл `modifiers`. Сохраняем сменные наборы под разные режимы.

## 6 (IMG_2825) — Руны
👁 Дерево с «вечными» (∞) множителями: урон 146, HP, HP базы 166; центральный узел 8/8.
⚙️ Перманентная прокачка силы — долгий сток ресурса, не сбрасывается престижем.
💡 Оставляем как долгую цель. Наш твист: часть рун меняет **поведение**, а не только числа — «раненые бойцы дерутся злее», «по истекающим кровью +урон», «шанс не уронить оружие». Синергия с моделью тела = интереснее плоских %.

## 7 (IMG_2826) — Герой (обзор)
👁 Экипируемый герой (Billie, ганфайтер) + слоты: оружие, аксессуары (ожерелья), корона, броня.
⚙️ Герой = лидер, шмот даёт глобальные баффы армии/базе.
💡 Герой — это **юнит-лидер на поле** с нашей полной моделью тела (может терять конечности, его лечат). Шмот меняет и цифры, и **стиль боя** (меч=ближний, пистолет=дальний в нашем движке).

## 8 (IMG_2827) — Аксессуар «Кровь гор» (легендарный)
👁 Уровень 15 (4/12): +58% урон, +250% крит-урон; пассив «HP базы ×1.15→1.16». Сетка ожерелий разных редкостей.
⚙️ Шмот-гача: редкости, дубли→уровень, легендарки дают жирные пассивы.
💡 Забираем систему редкостей/прокачки шмота. Наш твист: легендарные пассивы **цепляют модель боя** — крит = шанс расчленить, вампиризм = хил при добивании, «морозный амулет» = удары могут заморозить.

## 9 (IMG_2828) — Оружие «Рубиновый меч» (легендарное)
👁 Уровень 13: +8% крит-шанс, +46% скорость атаки; пассив «урон всех юнитов ×1.38→1.41». Сетка мечей.
⚙️ Оружие героя = крупный глобальный бафф + свои статы.
💡 Оружие определяет **мувсет/анимацию** героя (наши клипы): рубиновый меч = быстрые удары; пистолет = дальний. Скины оружия — из твоего пайплайна генерации. Бафф на всех юнитов.

## Итог для разработки
Забираем каркас (ядро боя, эпохи, герой+шмот, подземелья, пасс, миссии, гача),
а **отличаемся глубиной боя**: реалистичная модель тела делает то, что в оригинале
плоские числа — зрелищным, тактическим и вирусным. Мета остаётся в слое игры и
входит в движок бандлом `modifiers` + вызовами `spawn/cast`.
